# 玩家行为分析与匹配系统

## 项目描述

玩家行为分析与匹配系统的bug修复项目。核心模块 `game/behavior_matching.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 技能计算只用段位不考虑胜率KDA命中率
- 匹配算法只用段位相近不考虑团队平衡
- 团队平衡完全没做一方高手一方菜鸟
- 行为分析完全没做不分析游戏风格
- 匹配超时后随便匹配无梯度无通知

## 运行测试

```bash
python -m pytest tests/test_behavior_matching.py -q
```

修复目标：所有 16 个测试全部通过。

- 不修改测试文件
